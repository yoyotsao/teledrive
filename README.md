# TeleDrive

A personal cloud storage system that uses Telegram as the storage backend. Files upload and download **directly between the browser and Telegram CDN via MTProto** — binary data never touches the backend server.

## Architecture

```
Upload:
  Browser ──(GramJS MTProto)──▶ Telegram CDN
      └── POST /api/v1/files/register ──▶ Backend (metadata only)

Download:
  Browser ──GET /api/v1/files/{id}/download──▶ Backend (returns message_id + access_hash)
      └───(GramJS MTProto)──▶ Telegram CDN ──▶ Browser
```

The backend stores only metadata (filename, size, message_id, access_hash, parent_id) in SQLite. No file data ever passes through it.

## Prerequisites

- [Docker](https://docs.docker.com/get-docker/) + Docker Compose
- Telegram API ID & Hash — from [my.telegram.org](https://my.telegram.org)
- Telegram session string (user account, not bot)

## Quick Start

### 1. Generate a session string

```bash
pip install telethon
python generate_session.py
```

### 2. Configure

```bash
cp .env.example .env
# Edit .env — fill in TELEGRAM_API_ID, TELEGRAM_API_HASH, TELEGRAM_SESSION_STRING
```

### 3. Start

```bash
docker compose up --build
```

Open [http://localhost:3000](http://localhost:3000).

To run in the background:

```bash
docker compose up -d --build
docker compose logs -f   # follow logs
```

### Stopping

```bash
docker compose down
```

## Environment Variables

| Variable | Required | Description |
|---|---|---|
| `TELEGRAM_API_ID` | Yes | From [my.telegram.org](https://my.telegram.org) |
| `TELEGRAM_API_HASH` | Yes | From [my.telegram.org](https://my.telegram.org) |
| `TELEGRAM_SESSION_STRING` | Yes | Generated by `generate_session.py` |
| `BACKEND_HOST` | No | Default `0.0.0.0` |
| `BACKEND_PORT` | No | Default `8000` |

## API Endpoints

All prefixed with `/api/v1`:

| Method | Path | Purpose |
|---|---|---|
| GET | `/files` | List files (supports `parent_id`, `split_group_id`, pagination) |
| GET | `/files/{id}` | Get file metadata |
| POST | `/files/register` | Register uploaded file (after GramJS upload) |
| PATCH | `/files/{id}` | Update metadata (thumbnail, parent_id) |
| DELETE | `/files/{id}` | Delete file |
| GET | `/files/{id}/download` | Get download metadata (message_id, access_hash) |
| GET | `/files/{id}/thumbnail` | Get thumbnail (JPEG) |
| GET | `/folders` | List folders |
| POST | `/folders` | Create folder |
| DELETE | `/folders/{id}` | Delete folder |

## Features

- Drag-and-drop upload (files and folders)
- Large file support: files >512MB are split into segments sharing a `split_group_id`
- Video/image thumbnails generated in-browser via Canvas, uploaded to Telegram
- Video streaming via MediaSource API + Service Worker
- Folder navigation with breadcrumb
- Grid and list views
- File renaming and move

## Troubleshooting

**Session string invalid** — Re-run `python generate_session.py` and update `.env`.

**Port already in use** — Stop the existing container: `docker compose down`.

**Thumbnail not showing** — The thumbnail is generated locally and uploaded concurrently with the file. If it's missing, delete any stale cache in `backend/thumbnails/` and refresh.

**Backend changes not applied** — Rebuild the image: `docker compose up --build`.
